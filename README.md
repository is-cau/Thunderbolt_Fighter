# Thunderbolt Fighter — 雷霆战机（可爱版）

## 概述

横版卷轴射击游戏（STG），Q版可爱画风。纯前端技术栈，单文件 `index.html`，零依赖。

- **游戏分辨率**：800×480（逻辑像素），自适应全屏
- **帧率**：60fps 固定时间步长（1/60s + 帧累积器）
- **平台**：桌面端（鼠标+键盘）/ 手机端（虚拟摇杆+自动横屏）

---

## 一、战机系统

### 1.1 基础属性
- 猫耳Q版战机，14×14px碰撞体积，半径6px
- 移动速度550px/s（鼠标跟随）、750px/s上限
- HP上限5，初始满血
- 无敌帧：受伤后2秒无敌闪烁

### 1.2 自动射击
- 射击间隔0.1秒（600发/分钟）
- 根据火力等级发射不同弹幕：

| 火力等级 | 子弹模式 |
|---|---|
| Lv1 | 单发 |
| Lv2 | 双发并排 |
| Lv3 | 三发扇形 |
| Lv4 | 三发 + 两侧斜角2发 |
| Lv5 | 三发 + 斜角2发 + 大角度2发（共7发） |

### 1.3 分数升级系统
- 每累计**100万分**，战机升级1级
- 升级效果：所有子弹**伤害+1**（基础伤害1 → Lv1=2 → Lv2=3...）
- HUD右上角显示当前等级和伤害倍率
- 升级时屏幕中央弹出"战机升级!"提示

### 1.4 道具系统
- 击杀敌人**35%概率**掉落道具
- 道具缓慢下落（80px/s）+ 正弦波摆动

| 道具 | 概率 | 效果 | 持续 |
|---|---|---|---|
| 散弹 | 35% | 火力升至Lv3 | 10秒 |
| 护盾 | 10% | +1最大HP，+1当前HP，蓝色光环 | 15秒 |
| 治疗 | 30% | +1当前HP | 即时 |
| 加速 | 25% | 移动速度×1.3 | 8秒 |

- Boss死亡掉落2个道具（不含治疗）

## 二、敌机系统

### 2.1 敌机类型

| 类型 | HP | 速度 | 碰撞 | 分值 | 射击 | 特点 |
|---|---|---|---|---|---|---|
| basic（团子） | 2 | 100 | 16px | 100 | 每2秒瞄准射击 | 圆形，愤怒眉毛 |
| fast（独眼） | 1 | 200 | 14px | 150 | 无 | 泪滴形，快速冲锋 |
| tank（坦克） | 5 | 60 | 24px | 300 | 每1.5秒瞄准 | 方形":3"脸 |
| swarmer（蜂群） | 1 | 150 | 10px | 50 | 无 | 金色小蜜蜂 |
| splitter（分裂） | 3 | 80 | 20px | 250 | 每2.5秒瞄准 | 星形，死亡分裂3只蜂群 |

### 2.2 HP递增
每波所有敌人HP × `(1 + (wave-1) × 0.2)`

| 波次 | HP倍率 |
|---|---|
| 1 | 1.0x |
| 5 | 1.8x |
| 10 | 2.8x |
| 15 | 3.8x |

### 2.3 移动模式
- `straight`：直线下落
- `sine`：正弦波摆动
- `zigzag`：锯齿形变向
- `circle`：圆形轨道
- `hover`：悬停+横向漂移
- `charge`：停顿后高速冲刺

## 三、Boss系统

### 3.1 出现规律
- 第**3/6/9/12/15波**（3的倍数）
- 15波后循环，数量×loopCount倍

### 3.2 属性
- 猫咪造型，120×84px碰撞，半径50
- HP = 波次定义值 × 2

| 波次 | 基础HP | 实际HP |
|---|---|---|
| 3 | 600 | 1,200 |
| 6 | 800 | 1,600 |
| 9 | 1,000 | 2,000 |
| 12 | 1,400 | 2,800 |
| 15 | 2,000 | 4,000 |

### 3.3 三阶段AI

| 阶段 | HP范围 | 移动 | 弹幕池 |
|---|---|---|---|
| 1 | >70% | 缓慢横移 | 瞄准、散射、双重 |
| 2 | 40-70% | 中等横移+上下浮动 | +环形、追踪、波浪 |
| 3 | <40% | 快速横移+大幅浮动 | +螺旋、爆发，追踪权重加倍 |

### 3.4 弹幕系统
- 每**3秒**随机切换一种弹幕模式
- 攻击间隔统一**2秒**
- Boss子弹**体积放大**（半径6×12px绘制，带光晕）

| 弹幕 | 描述 |
|---|---|
| 瞄准 | 1发瞄准玩家 |
| 散射 | 5发扇形 |
| 双重 | 2发大角度 |
| 环形 | 16发360° |
| 追踪 | 4发红色跟踪弹（速度60，跟踪3秒） |
| 波浪 | 10发正弦波 |
| 螺旋 | 20发旋转扩散 |
| 爆发 | 8发加速扩散 |

### 3.5 追踪弹
- 红色脉冲光晕显示
- 自动转向玩家，速度60px/s
- 持续3秒后停止追踪
- Boss死亡时清除所有敌方子弹

### 3.6 Boss流程
1. 小兵清完 → Boss警告2秒（红色闪烁边框+"警告！BOSS来袭！"）
2. Boss从天而降至Y=100位置
3. Boss战中环境怪继续刷新
4. Boss死亡 → 清小兵+清子弹 → 慢动作1.5秒 → 掉落道具 → 进入下一波

## 四、自动技能系统

### 4.1 触发机制
- 每个技能有独立冷却时间
- 冷却完毕后**立即自动释放**（不等定时器）
- 闪电链独立运行（可与其他技能并发）
- Boss警告期间暂停触发

### 4.2 技能详情

| 技能 | 冷却 | 持续 | 效果 |
|---|---|---|---|
| 闪电链 | 1s×0.9递减至0.1s | 3.6s | 从战机链式跳跃6个敌人，伤害4/帧，60px半径内子弹湮灭 |
| 神龙摆尾 | 6-8s | 2.0s | 7发强化子弹（伤害2）扇形扫射 |
| 冲击波 | 6-8s | 1.2s | 5波递增360°弹幕（46→56→66→76→86发，每0.2s一波） |
| 流星雨 | 6-8s | 4.0s | 向上发射50颗火球，伤害8，碰撞半径35px |
| 散射弹幕 | 6-8s | 3.0s | 高速5发宽锥形射击 |
| 侧方射击 | 6-8s | 3.0s | 左右各5发+上方1发 |
| 寒冰风暴 | 8s | 2.0s冻结+3.0s减速 | 冻结非Boss敌人（冰晶环绕），解冻后减速3秒（虚线标记） |

### 4.3 闪电链特殊机制
- Wave 1-4：1条
- Wave 5-9：**2条并发**
- Wave 10+：**3条并发**
- 每条独立3.6秒，冷却每次×0.9递减

### 4.4 寒冰风暴
- 冻结：敌人原地不动，蓝色冰晶光环+6根冰刺
- 敌方子弹减速70%
- 解冻后：敌人40%速度持续3秒

## 五、波次系统

### 5.1 波次结构
- 15个预定义波次，循环递增
- 每波包含若干敌机组（类型、数量、刷新模式、延迟）
- 敌机组随机打乱实现混合刷新

### 5.2 出怪速度
- 每波出怪速度 × `(1 + wave × 0.5)` 加速
- 前10秒暖机：初始3倍慢，线性恢复

### 5.3 环境刷怪
- 波间持续刷新，指数衰减曲线：`0.5 × 0.7^(wave-1) + 0.03` 秒间隔
- 集群刷新：50-95%概率，2-8只/组
- 敌机类型随波次丰富

### 5.4 波次切换
- 非Boss波：队列刷完 → 3秒后自动进入下一波
- Boss波：小兵清完 → 警告 → Boss战 → Boss死 → 清场 → 0.3秒后下一波

## 六、碰撞与伤害

### 6.1 碰撞系统
- 圆形碰撞检测（圆-圆距离 < 半径和）
- 每帧检测：玩家子弹×敌方 / 敌方子弹×玩家 / 敌机×玩家 / 道具×玩家
- 玩家子弹×敌方子弹：**相互抵消**，产生金色粒子

### 6.2 连击系统
- 连续击杀计数，1.5秒内无击杀归零
- 分数倍率：

| 连击数 | 倍率 | 里程碑文字 |
|---|---|---|
| 10-24 | 2x | 不错! |
| 25-49 | 3x | 太棒了! |
| 50-99 | 5x | 惊人! |
| 100+ | 10x | 完美! |

## 七、视觉特效

- **爆炸粒子**：彩色碎片+火花+光环，数量15-60根据敌机类型
- **Boss爆炸**：60粒子+10碎片+3层光环+白屏闪+强震
- **屏幕震动**：受击8px、Boss死亡15px，指数衰减

- **冻结/减速特效**：冰晶光环旋转、虚线标记
- **追踪弹**：红色脉冲光晕

## 八、音效系统

- 全部通过 Web Audio API 程序化生成
- 射击：方波扫描（800→400Hz，80ms）
- 爆炸：白噪声爆发+低频三角波
- 连击：三角波琶音（C-E-G），高连击叠加高频泛音
- Boss警告：双频交替方波（440/554Hz）
- Boss死亡：噪声+锯齿波下行+三音下行和弦
- 背景音乐：C大调五声音阶8音循环，三角波
