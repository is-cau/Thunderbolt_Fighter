# Thunderbolt Fighter — 雷霆战机（可爱版）

一款基于浏览器的横版卷轴射击游戏，采用可爱/Q版画风。纯前端技术构建 —— 单文件 HTML，零依赖。

## 开始游戏

在任意现代浏览器（推荐 Chrome / Firefox / Edge）中打开 `index.html` 即可。

## 操作方式

| 操作 | 输入 |
|---|---|
| 移动 | **鼠标**（主要方式）或 WASD / 方向键 |
| 射击 | **自动射击**（始终开启） |
| 暂停 | **P** |
| 开始 / 重新开始 | 点击画布或按钮 |

## 功能特性

- **可爱画风**：带有猫耳和腮红的 Q 版战机，5 种个性鲜明的敌机，猫咪 BOSS（皇冠+旋转炮塔+受伤红眼）
- **5 种敌机**：基础团子、快速独眼怪、坦克 ":3" 机器人、蜂群、分裂星星
- **15 波关卡**（循环递增），第 3/6/9/12/15 波为 BOSS 战
- **6 种自动技能**（冷却即放）：
  - 闪电链（从战机发射链式跳跃，冷却递减至0.1秒）
  - 神龙摆尾（扇形强化子弹）
  - 冲击波（3波递增360°弹幕）
  - 流星雨（向上50颗火球）
  - 散射弹幕（高速宽锥形射击）
  - 侧方射击（左右同时开火）
- **BOSS 弹幕系统**：每3秒切换攻击模式，共8种弹幕
  - 瞄准射击、散射、双重射击、环形弹幕（16发）
  - 追踪弹（红色跟踪4发）、波浪弹幕（10发正弦波）
  - 螺旋弹幕（20发旋转扩散）、爆发弹幕（8发加速扩散）
- **出怪递增**：前10秒暖机，之后随波次爆炸增长，每波敌人 HP +20%
- **子弹抵消**：玩家子弹可与敌方子弹碰撞抵消
- **道具系统**：散弹射击、护盾（+1 HP + 光环）、治疗（+1 HP）、加速
- **连击系统**：100 连击 = 10 倍分数，里程碑特效
- **粒子特效**：火花/光环/碎片爆炸、屏幕震动、白屏闪白、慢动作
- **程序化音频**：Web Audio API 生成全部音效与音乐
- **全部资源程序化**：Canvas API 绘制所有精灵，零图片零音频文件
- **响应式设计**：自适应任意屏幕尺寸

## 技术栈

- HTML5 Canvas、Web Audio API、原生 JavaScript
- 单文件，零依赖
