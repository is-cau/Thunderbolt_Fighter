# Thunderbolt Fighter — 雷霆战机（可爱版）

一款基于浏览器的横版卷轴射击游戏，采用可爱/Q版画风。纯前端技术构建 —— 单文件 HTML，零依赖。

## 开始游戏

在任意现代浏览器中打开 `index.html` 即可。

## 操作方式

| 操作 | 输入 |
|---|---|
| 移动 | **鼠标** 或 WASD / 方向键 |
| 射击 | **自动射击** |
| 暂停 | **P** |
| 开始 / 重开 | 点击画布或按钮 |

## 游戏系统

### 战机
- Q版猫耳战机，鼠标跟随移动，自动射击
- 道具：散弹（3发扇形）、护盾（+1HP+光环）、治疗（+1HP）、加速

### 敌机（5种）
- 基础团子、快速独眼怪、坦克":3"机器人、蜂群、分裂星星（死亡分裂3只蜂群）
- 每波 HP +20%，环境怪随波次递增

### BOSS（第3/6/9/12/15波）
- 猫咪Boss，带皇冠、旋转炮塔、受伤红眼+愤怒眉毛
- 三阶段 AI（HP>70%/40-70%/<40%）
- 每3秒切换弹幕模式，共8种：
  - 瞄准射击、散射、双重射击
  - 环形弹幕（16发）、追踪弹（红色4发）
  - 波浪弹幕（10发正弦波）、螺旋弹幕（20发旋转）
  - 爆发弹幕（8发加速扩散）
- 子弹体积放大，追踪弹从身体发出
- 攻击间隔2秒，HP=定义值×2

### 自动技能（6种，冷却即放）
| 技能 | 持续 | 说明 |
|---|---|---|
| 闪电链 | 1.2s | 从战机链式跳跃，冷却每次×0.9递减至0.1s |
| 神龙摆尾 | 2.0s | 7发强化子弹扇形扫射 |
| 冲击波 | 1.2s | 5波递增360°弹幕（46/56/66/76/86发） |
| 流星雨 | 4.0s | 向上发射50颗火球，伤害8点，碰撞35px |
| 散射弹幕 | 3.0s | 高速5发宽锥形射击 |
| 侧方射击 | 3.0s | 左右各5发+上方1发 |

### 连击系统
- 10/25/50/100 连击触发里程碑（不错!/太棒了!/惊人!/完美!）
- 100连击=10倍分数

### 其他
- 子弹抵消：玩家子弹可抵消敌方子弹
- 前10秒暖机慢出怪，之后每波出怪速度+80%
- 15波后循环最后波定义，数量×loopCount
- 屏幕底部技能冷却条实时显示

## 技术栈

HTML5 Canvas · Web Audio API · 原生 JavaScript · 单文件零依赖
