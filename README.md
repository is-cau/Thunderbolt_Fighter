# Thunderbolt Fighter — 雷霆战机（可爱版）

一款基于浏览器的横版卷轴射击游戏，采用可爱/Q版画风。使用纯前端技术构建 —— 单文件 HTML，零依赖。

## 开始游戏

在任意现代浏览器（推荐 Chrome / Firefox / Edge）中打开 `index.html` 即可。

## 操作方式

| 操作 | 输入 |
|---|---|
| 移动 | **鼠标**（主要方式）或 WASD / 方向键 |
| 射击 | **自动射击**（始终开启） |
| 暂停 | **P** |
| 开始 / 重新开始 | 点击画布或按钮 |

## 功能特性

- **可爱画风**：带有猫耳和腮红的 Q 版战机，5 种个性鲜明的敌机类型，猫咪造型的 Boss
- **5 种敌机类型**：基础团子、快速独眼怪、坦克 ":3" 机器人、蜂群敌人、分裂星星
- **15 波关卡**（循环递增），难度持续递增，第 3/6/9/12/15 波（3的倍数）为 Boss 战（三阶段 Boss AI）
- **6 种自动间隔特殊效果**（每3-6秒随机触发）：
  - 闪电链（从战机发射，链式跳跃，冷却1秒）
  - 激光扫射（扇形强化子弹）
  - 旋转爆射（3波递增360°弹幕）
  - 流星雨（天降火球）
  - 散射弹幕（高速宽锥形射击）
  - 侧方射击（左右同时开火）
- **出怪递增**：前10秒暖机慢出怪，之后随波次爆炸式增长，15波后循环加倍，每波敌人HP+20%
- **子弹抵消**：玩家子弹可与敌方子弹碰撞抵消
- **道具系统**：散弹射击、护盾（+1 HP + 护盾光环）、治疗（+1 HP）、加速
- **连击系统**：100 连击以上可获得 10 倍分数加成，并伴有里程碑特效
- **粒子特效**：带有火花、光环、碎片的爆炸效果，屏幕震动、白屏闪白、慢动作
- **程序化音频**：所有音效均通过 Web Audio API 生成 —— 无需音频文件
- **全部资源程序化生成**：所有精灵图均通过 Canvas API 绘制 —— 无需图片文件
- **响应式设计**：自适应任意屏幕尺寸

## 技术栈

- HTML5 Canvas（全部渲染）
- Web Audio API（全部音效与音乐）
- 原生 JavaScript（无框架，无依赖）
