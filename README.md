# Thunderbolt Fighter — 雷霆战机（可爱版）

横版卷轴射击游戏，Q版画风，纯前端单文件零依赖。

## 操作

| 操作 | 桌面端 | 手机端 |
|---|---|---|
| 移动 | 鼠标 / WASD | 虚拟摇杆 |
| 射击 | 自动 | 自动 |
| 暂停 | P | P |
| 全屏横屏 | — | 点击开始自动触发 |

## 战机系统

- Q版猫耳战机，自动射击
- **分数升级**：每100万分战机升级，子弹伤害+1（1M=2倍，2M=3倍...），HUD显示等级
- 道具：散弹、护盾（+1HP+光环）、治疗（+1HP）、加速

## 敌机（5种）
基础团子、快速独眼怪、坦克":3"机器人、蜂群、分裂星星（死亡分裂3只）

## BOSS（第3/6/9/12/15波）
猫咪Boss带皇冠+旋转炮塔，三阶段AI，每3秒切换弹幕（8种：瞄准/散射/双重/环形/追踪/波浪/螺旋/爆发），子弹放大，追踪弹从身体发出

## 自动技能（7种，冷却即放）

| 技能 | 冷却 | 说明 |
|---|---|---|
| 闪电链 | 1s递减至0.1s | 从战机链式跳跃，后期最多3条并发，60px内子弹湮灭 |
| 神龙摆尾 | 6-8s | 扇形强化子弹 |
| 冲击波 | 6-8s | 5波递增360°弹幕 |
| 流星雨 | 6-8s | 向上50颗火球，伤害8 |
| 散射弹幕 | 6-8s | 高速宽锥形射击 |
| 侧方射击 | 6-8s | 左右同时开火 |
| 寒冰风暴 | 8s | 冻结敌人2s（冰晶环绕）+ 解冻减速3s（虚线标记） |

## 其他

- 出怪：前10秒暖机，每波HP+20%，15波后循环加倍
- 子弹抵消，连击系统（100连=10倍分）
- 粒子特效、屏幕震动、慢动作
- 手机端自动全屏横屏

## 技术栈

HTML5 Canvas · Web Audio API · 原生JS · 单文件零依赖
