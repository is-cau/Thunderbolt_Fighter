# Thunderbolt Fighter — 雷霆战机（可爱版）

一款基于浏览器的竖版卷轴射击游戏，采用可爱/Q版画风。使用纯前端技术构建 —— 单文件 HTML，零依赖。

## 开始游戏

在任意现代浏览器（推荐 Chrome / Firefox / Edge）中打开 `index.html` 即可。

## 操作方式

| 操作 | 输入 |
|---|---|
| 移动 | **鼠标**（主要方式）或 WASD / 方向键 |
| 射击 | **自动射击**（始终开启） |
| 全屏激光 | **F1**（冷却时间 16 秒） |
| 暂停 | **P** |
| 开始 / 重新开始 | 点击画布或按钮 |

移动端：虚拟摇杆 + 射击按钮（在触屏设备上自动检测并启用）。

## 功能特性

- **可爱画风**：带有猫耳和腮红的 Q 版战机，5 种个性鲜明的敌机类型，猫咪造型的 Boss
- **5 种敌机类型**：基础团子、快速独眼怪、坦克 ":3" 机器人、蜂群敌人、分裂星星
- **15 波关卡**，难度逐步递增，第 5/10/15 波为 Boss 战（三阶段 Boss AI）
- **F1 全屏激光**：具有冷却时间的毁灭性清屏技能
- **Roguelike 体验**：波次之间持续生成环境敌人，分裂类敌人会生成子单位
- **道具系统**：散弹射击、护盾（+1 HP）、治疗（+2 HP）、加速
- **连击系统**：100 连击以上可获得 10 倍分数加成，并伴有里程碑特效
- **粒子特效**：带有火花、光环、碎片的爆炸效果，屏幕震动、白屏闪白、慢动作
- **程序化音频**：所有音效均通过 Web Audio API 生成 —— 无需音频文件
- **全部资源程序化生成**：所有精灵图均通过 Canvas API 绘制 —— 无需图片文件
- **响应式设计**：自适应任意屏幕尺寸

## 技术栈

- HTML5 Canvas（全部渲染）
- Web Audio API（全部音效与音乐）
- 原生 JavaScript（无框架，无依赖）
- 单文件：约 1500 行
