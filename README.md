# Thunderbolt Fighter — 雷霆战机（可爱版）

横版卷轴射击游戏（STG），Q版可爱画风。纯前端单文件 `index.html`，零依赖。

# 体验链接

## [点击即玩](https://is-cau.github.io/Thunderbolt_Fighter/)


## 操作

| 操作 | 桌面端 | 手机端 |
|---|---|---|
| 移动 | 鼠标 / WASD | 左下虚拟摇杆 |
| 射击 | 自动 | 自动（右下FIRE按钮纯视觉反馈） |
| 暂停 | P | P |
| 横屏全屏 | — | 点击开始自动触发 |

## 战机系统

- Q版猫耳战机，14×14px碰撞，半径6px，HP上限10
- 自动射击间隔0.1s，火力等级1-5（多方向弹幕）
- **分数升级**：每100万分战机升级1级，子弹伤害+1（1M=2倍，2M=3倍...），HUD显示
- 受伤后2秒无敌闪烁，Boss死亡时5秒无敌
- **宇宙大爆发**：HP降至3时自动触发，无视冷却同时释放神龙摆尾+冲击波+寒冰风暴（白屏闪+强震+低频轰鸣）
- 道具掉落率35%：散弹(35%)、护盾(10%)、治疗(30%)、加速(25%)

## 敌机（5种）

| 类型 | HP | 速度 | 特点 |
|---|---|---|---|
| basic（团子） | 2 | 100 | 圆形，愤怒眉毛，瞄准射击 |
| fast（独眼） | 1 | 200 | 泪滴形，快速冲锋 |
| tank（坦克） | 5 | 60 | ":3"脸，慢速厚血 |
| swarmer（蜂群） | 1 | 150 | 金色小蜜蜂，成群出现 |
| splitter（分裂） | 3 | 80 | 星形，死亡分裂3只蜂群 |

每波HP +20%，6种移动模式（直线/正弦/锯齿/圆轨/悬停/冲刺）

## BOSS（第3/6/9/12/15波）

猫咪Boss带皇冠+旋转炮塔，三阶段AI，每3秒切换弹幕，攻击间隔2秒，共8种弹幕模式。追踪弹从身体发出，红色脉冲显示。Boss死亡清除所有敌方子弹。

## 出怪系统

- 前10秒暖机慢出，之后指数衰减曲线：`0.5 × 0.7^(wave-1) + 0.03`秒间隔
- 集群刷新：50-95%概率，2-8只/组
- 15波后循环递增，数量×loopCount倍

## 其他系统

- 子弹抵消 / 连击系统（100连=10倍分）/ 分数升级
- 粒子特效（爆炸/火花/光环/冰晶）、屏幕震动、慢动作
- Web Audio API 程序化音效+音乐
- 技能冷却条实时显示

## 技术栈

HTML5 Canvas · Web Audio API · 原生JS · 单文件
